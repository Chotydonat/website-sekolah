# Website Dayah Jeumala Amal — Landing Page + Dasbor Admin & PPDB

Frontend statis untuk GitHub Pages. Backend (Google Apps Script) dikirim terpisah dan **tidak** ada di folder ini.

```
index.html        website publik (SPA: beranda, profil, berita, daftar PPDB, cek status, verifikasi dokumen)
admin.html        dasbor admin (login Google / akses darurat tersembunyi)
css/  js/  assets/
js/config.js      ← WAJIB isi GAS_URL (URL /exec dari Apps Script)
PANDUAN-INSTALASI.md
```

Folder ini adalah folder yang di-`git init` (lihat PANDUAN-INSTALASI.md bagian D).
